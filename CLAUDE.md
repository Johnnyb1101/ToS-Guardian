# ToS Guardian

- Code comments only when absolutely necessary to explain obscure code. No file headers, no narration of what the code does, no restating names. Explanations belong in docs/ and README files.
- Zero user data leaves the extension: site and document facts only. Never a page URL, page text, button label, user action, identifier, or IP.
- Tests are standalone Node scripts chained in `npm test`. Add regression tests in that style.
- The owner makes every commit and merge. Stop at each checkpoint with evidence.
